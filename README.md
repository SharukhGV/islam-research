# Quran & Hadith Desktop Application 📖

An offline-first desktop application designed to provide fast, private access to the **Qur’an** and **Hadith collections** for reading, searching, and research purposes. All data is bundled locally within the application to respect user privacy and enable full offline use.

---

## 🕌 Purpose & Intent

The goal of this application is to offer:
- Fast desktop-based searching of Qur’an and Hadith
- Offline access without relying on external APIs
- Privacy-respecting research tools for students and general users

This app is intended as a **research and reference tool**, not as a substitute for scholarly study.

---

## ✨ Key Features

- 📖 Complete Qur’an text with English translation
- 📚 Multiple Hadith collections included locally
- 🔍 Fast search using **Arabic or English**
- 📴 Fully **offline functionality**
- 🖥 Desktop application experience
- 🔒 No tracking, no online fetching of content

---

## 🛠 Tech Stack

- **Platform:** Desktop Application
- **Frontend:** JavaScript / HTML / CSS
- **Framework:** Electron
- **Data:** Local JSON datasets
- **Search:** Client-side indexing for fast lookups
